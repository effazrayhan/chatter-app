# Pulse UI references

These raster mockups are visual references for the Compose screens. They are kept outside `app/src/main/res` so they do not change the runtime APK by themselves.

- `pulse-chat-list.png`: chat list, search, unread badges, pinned and muted rows.
- `pulse-chat-screen.png`: one-to-one conversation, reactions, media message, reply preview, and composer.
- `pulse-profile-settings.png`: profile header and settings controls.

They were generated as product-design references and should be translated into accessible Compose components, strings, and theme tokens rather than copied as a screenshot into the app UI.
